# EventIQ – AI-Powered Smart Event Planning & Vendor Marketplace

🌐 Live Website: https://eventiq-frontend.vercel.app/

EventIQ is an AI-powered event management platform designed to simplify event planning through intelligent vendor recommendations, data-driven decision-making, and budget optimization.

The platform helps users discover suitable event vendors based on their requirements, compare available options, and create optimized event plans while staying within their budgets.

## 🎯 Problem Statement

Planning an event involves coordinating multiple vendors, managing budgets, comparing pricing, and ensuring availability. These processes are often time-consuming and fragmented.

EventIQ addresses these challenges by bringing vendor discovery, intelligent recommendations, and budget planning into a unified platform.

## ✨ Key Features

- **AI-Powered Vendor Recommendations:** Recommends suitable vendors using machine learning-based scoring.
- **Smart Vendor Filtering:** Filters vendors based on event requirements, including locality, guest capacity, availability, and pricing.
- **Vendor Scoring System:** Evaluates and ranks vendors to help users make informed decisions.
- **Budget Optimization:** Helps allocate the available budget across different event requirements.
- **Personalized Event Planning:** Supports different planning approaches, including Budget, Balanced, and Premium plans.
- **Data-Driven Insights:** Uses data analysis and machine learning to improve recommendation quality.

## 🧠 Machine Learning & Data Processing

The ML component focuses on improving vendor discovery and recommendation quality.

Key activities include:

1. Dataset investigation and exploratory data analysis.
2. Data cleaning and preprocessing.
3. Feature engineering for vendor attributes.
4. Development of a vendor scoring mechanism.
5. Ranking vendors based on user requirements.
6. Model validation and performance evaluation.

The vendor scoring model achieved approximately **92% accuracy** in the reported evaluation.

## 🏗️ System Architecture

The platform follows a modular architecture:

1. **User Interface:** Collects event requirements and user preferences.
2. **Backend API:** Processes requests and coordinates application components.
3. **AI Planning Engine:** Handles vendor recommendations, scoring, and budget optimization.
4. **Database:** Stores vendor information and relevant application data.
5. **Recommendation Output:** Returns suitable vendors and optimized planning suggestions.
